# ADR 0002：D04 暂保留自研默认，继续隔离评测与 Android 实验

日期：2026-11-08。状态：临时决策；完整 D04 仍待 Android 与独立验收。

## 背景

阶段一提供了 InputEngine 替换接口，当前中文质量仍低于产品目标。需要比较复用成熟引擎与继续自研的收益和成本，不能仅凭引擎知名度迁移。

## 证据

同一 v2 dev 上，自研 Top1/Top5=51.59%/72.33%，librime 1.17.0 + 固定 pinyin_simp 最小方案=41.40%/43.42%。专名类别存在互补优势。两套词库和候选组织不同，这不是纯算法消融。v2 与自研生产 n-gram 统计训练源重合，尚无训练源独立的泛化验收。

详见 `docs/D04_HOST_COMPARISON.md`，包括固定版本、分类指标、评分修正、可复现工具与限制。

## 决策

保持生产 PinyinInputEngine；不加入生产开关或 native 依赖，不按 dev 结果自动选择某个引擎。不宣称 Rime 无价值，也不以宿主速度替代 Android 性能证据。

先修复训练源隔离并冻结验收口径，然后继续更完整方案/同词典对照与独立 Android PoC。只有质量、消费范围/取消/学习契约、设备预算与许可都得到证据后才更新选型。

## 后果与重新决策条件

短期不会因迁移破坏已验收状态机；自研的长句和纠错短板仍然存在。本次试验不授权持续增加自研特例，也不意味着选择了长期自研路线。

当一套可部署的候选组合在隔离验收集和同机测试中达到既定门槛，或者自研在连续两轮泛化实验中没有实质收益，应重新比较并更新本 ADR。
