# ADR 0002：D04 暂保留自研默认，继续隔离评测与 Android 实验

日期：2026-11-08。状态：临时决策；完整 D04 仍待 Android 与独立验收。

## 背景

阶段一提供了 InputEngine 替换接口，当前中文质量仍低于产品目标。需要比较复用成熟引擎与继续自研的收益和成本，不能仅凭引擎知名度迁移。

## 证据

同一 v2 dev 上，自研 Top1/Top5=51.59%/72.33%，librime 1.17.0 + 固定 pinyin_simp 最小方案=41.40%/43.42%；换成项目同一词表后 Rime=32.15%/33.67%，说明“不同词典”差值中有明显词典/权重贡献，不能解释为纯引擎能力。专名类别存在互补优势。两套候选组织不同，这不是纯算法消融。

v2 与自研生产 n-gram 统计训练源重合。新增训练源独立的 v3 CC0 验收集（601 条）首轮基线：Top1 38.8%、Top5 59.4%、rankCost 4.61、oracle 77.0%，明显低于 v2，证明 v2 分数被同源数据高估。v3 只作验收、未用于调参。

详见 `docs/D04_HOST_COMPARISON.md`、`docs/D04_SAME_DICTIONARY.md`、`docs/EVALUATION_V3_PROTOCOL.md` 与 `docs/EVALUATION_V3_BASELINE.md`，包括固定版本、分类指标、评分修正、可复现工具与限制。

## 决策

保持生产 PinyinInputEngine；不加入生产开关或 native 依赖，不按 dev 结果自动选择某个引擎。不宣称 Rime 无价值，也不以宿主速度替代 Android 性能证据。

训练源隔离与 v3 独立验收口径已建立；同词典对照已完成（仍为宿主）。下一步继续更完整 Rime 方案/Android JNI PoC 和设备实测。只有质量、消费范围/取消/学习契约、设备预算与许可都得到证据后才更新选型。

## 后果与重新决策条件

短期不会因迁移破坏已验收状态机；自研的长句和纠错短板仍然存在。本次试验不授权持续增加自研特例，也不意味着选择了长期自研路线。

当一套可部署的候选组合在隔离验收集和同机测试中达到既定门槛，或者自研在连续两轮泛化实验中没有实质收益，应重新比较并更新本 ADR。
