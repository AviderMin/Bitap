# Bitap 产品简报

版本：0.1（MVP）｜状态：范围冻结｜负责人：Lead｜更新：2026-11-06

## 1. 一句话

Bitap 是一款把「安静、准确、可信」放在第一位的 Android 输入法：默认离线，本地 AI 只在用户明确需要时出现，做完事就退场。

## 2. 问题与用户

目标用户是每天在手机上中英文混输、在意输入隐私、又愿意为更好的表达多花一秒的人。他们不需要一个会抢注意力的 AI 助手，只需要：

1. 按键跟手，候选准确；
2. 想润色一句话时，不必切换 App；
3. 不必担心输入内容被上传、训练或分析。

## 3. 产品原则

| 原则 | 可执行定义 |
| --- | --- |
| 隐私是架构 | 无 `INTERNET` 权限；无分析 SDK；无账号；输入文本不落盘；模型与词库都在本地。 |
| AI 克制 | AI 永不自动触发、永不自动发送；每次操作必须由用户点击，并先预览、后插入。 |
| 小而美 | 首页只做三件事：启用、选主题、装模型。键盘只保留候选、字母与必要功能键。 |
| 精准 | 拼音候选优先来自本地词库；AI 只作为本地候选扩充器，限制上下文与候选数量，宁可不答也不胡说。 |

## 4. MVP 范围

### 包含

- Android 13（API 33）及以上。
- 中文拼音输入：全拼、离线候选、单字与词组；英文 QWERTY；数字与常用符号。
- 候选栏、退格、回车、空格、Shift、中英切换、符号层。
- AI 词库：用户点击 `✦ AI` 后，根据拼音/上下文生成本地中文候选，点选才上屏；不自动触发、不改写整段文字。
- 本地模型管理：通过系统文件选择器导入 `.litertlm`，私有目录保存，可删除。
- App 双主题：Miuix（清透）与 Glasmio（流光）；键盘另有独立的纸白/墨玉/极光主题与整体高度设置。
- 键盘高度可调：85%–135% 滑杆，适配小屏、单手与大屏。
- 首次使用引导、启用键盘入口、输入法选择入口、隐私说明。

### 不包含（0.1 明确不做）

- 云同步、云 AI、账号体系、数据统计。
- 语音输入、手写、手势滑行输入、表情预测。
- 联网下载模型（模型由用户在外部获取后导入）。
- 个性化学习、输入历史、联系人词库。
- iOS / 桌面端。

## 5. 体验承诺

- 从点击输入框到键盘出现：中端机 p90 ≤ 300 ms。
- 普通按键到字符上屏：p95 ≤ 50 ms（拼音候选计算异步，不阻塞上屏）。
- AI 首 token：Qwen3-0.6B INT4、8 GB RAM 设备 p50 ≤ 2.5 s；超时 20 s 自动取消。
- 视觉：键盘高度不超过屏幕 45%，单手可触达核心键区。
- 无障碍：所有键 ≥ 48 dp，支持 TalkBack 描述与触觉反馈。

## 6. 成功指标（0.1 人工验收）

- `aapt dump permissions` 无 `android.permission.INTERNET`。
- `assembleDebug` 与 `testDebugUnitTest` 通过。
- 双主题在浅色/深色下均无对比度不足或键盘裁切。
- 断网、飞行模式下所有本地功能可用。
- AI 按钮在未安装模型时明确提示，不崩溃、不静默失败。
