# Bitap 体验规范

版本：0.1｜状态：冻结｜依赖：[产品简报](00-product-brief.md)

## 1. 首次使用

1. 打开 Bitap，看到品牌页与两个主题样例（Miuix 清透 / Glasmio 流光）。
2. 三步清单：
   - **启用 Bitap 键盘**：跳转系统「输入法」设置；
   - **切换到 Bitap**：跳转系统输入法选择器；
   - **导入本地模型（可选）**：打开系统文件选择器，选择 `.litertlm`。
3. 每一步完成后显示对勾；未完成不阻塞其他步骤。
4. 主题选择即时预览，立即写入本地偏好。

## 2. 键盘布局

```
┌──────────────────────────────────────────┐
│ 候选条：拼音/预测候选  ·  ✦ AI            │  40–44 dp
├──────────────────────────────────────────┤
│ Q W E R T Y U I O P                      │
│  A S D F G H J K L                       │
│   ⇧ Z X C V B N M ⌫                     │
├──────────────────────────────────────────┤
│ 123  🌐/中   ,     空格     .   ↵         │  功能行
└──────────────────────────────────────────┘
```

- 字母键高度随屏幕自适应；默认键高 54 dp，整块键盘 ≤ 可用高度 50%。
- 用户可在 Bitap 首页「键盘 → 键盘高度」中用 85%–135% 滑杆调整（默认 100%，步进 5%）；调整后下一次弹出键盘生效。
- 键帽按下时缩放 0.96、阴影收敛；松手 90–140 ms 回弹。
- 空格键长按无动作（0.1 不做语音）；AI 通过候选条右侧 ✦ 显式触发。
- 中文模式：字母进入拼音 composing，候选条实时刷新；空格提交首选候选；无候选时空格输入空格。
- 英文模式：直接上屏；Shift 单击切大写，双击锁定；中英切换键显示当前目标语言。
- 符号层：`123` 进入数字/常用符号；再点 `#+=` 进入更多符号；`ABC` 返回字母。

## 3. AI 改写流程

**触发**：用户点击候选条右侧 ✦（仅在设置开启且模型已就绪时可见/可用）。

**面板**：
1. 顶部显示来源文本（最多两行，超出省略）；
2. 四个动作 chip：润色 / 精简 / 正式 / 译为英文；
3. 点击后进入「思考中」，可取消；
4. 流式结果展示在面板内，最多 6 行，可滚动；
5. 底部两个动作：**插入**（替换选中文本或插入到光标）与 **放弃**。
6. AI 结果不会自动上屏；点击插入之前，原文保持不变。

**安全边界**：
- 只读取用户主动触发时的当前选中文本；若无选中，读取光标前最近一句（≤512 字符）。
- 不读取剪贴板、不读取其他 App、不保存 prompt/结果。
- 生成结果做基本清理：去掉包裹引号、Markdown 标记与「以下是改写」类前言；长度超过原文 3 倍时截断并提示。
- 未安装模型：✦ 显示禁用态；点击弹出「导入 Qwen3-0.6B」入口。

## 4. 主题

- Miuix「清透」：浅色为暖白底、纯白键帽、细描边与克制的蓝色强调；深色为墨黑底、石墨键帽。
- Glasmio「流光」：键盘下方有低饱和极光渐变，键帽为半透明玻璃，带边缘高光与轻微折射；深色模式降低透明度而不牺牲可读性。
- 两套主题共享同一布局与交互，只替换视觉 token；切换主题不重建输入状态。

## 5. 状态与反馈

| 场景 | 反馈 |
| --- | --- |
| 按键 | 默认轻触觉；可在设置关闭；不播放声音（默认）。 |
| 拼音无候选 | 候选栏显示原始拼音，回车提交原文。 |
| AI 加载中 | 面板顶部显示细进度条与「本地思考中…」，可取消。 |
| AI 失败/超时 | 「这次没想好」+ 重试 / 放弃；不弹系统对话框。 |
| 模型导入中 | 显示字节进度；可取消；失败清理临时文件。 |
| 模型损坏 | 「模型文件不完整」+ 重新导入。 |

## 6. 无障碍与国际化

- 每个键提供 `contentDescription`（如「删除」「切换到中文」）。
- 支持系统字体缩放至 1.3×；候选条可横向滚动。
- 文案以简体中文为主，英文模式 UI 保留中文品牌词；后续可加英文资源。
- 触摸目标最小 48×48 dp；颜色对比度 ≥ 4.5:1（正文）/ 3:1（大字号）。

## 7. 明确不做

不做自动补全整句、不做读取屏幕、不做云端改写、不做输入统计、不做基于联系人的候选。
