# Bitap 本地 AI 设计

版本：0.1｜状态：冻结｜依赖：[架构设计](02-architecture.md)

## 1. 目标

让用户在键盘内完成「一句话的最后一公里」：润色、精简、正式化、译成英文。AI 必须 **本地、短、可撤销、可预期**。

## 2. 模型与运行时

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 模型 | Qwen3-0.6B（优先 INT4 `.litertlm`，约 332 MB） | 0.6B 级别可在手机运行；中文能力足够做短句改写；Apache-2.0。 |
| 运行时 | LiteRT-LM 0.19.1 Android | Google AI Edge 官方 Kotlin API；预编译 AAR，无需 NDK/CMake；支持 CPU/GPU。 |
| 后端 | CPU（0.1 默认） | 兼容性最好；GPU 作为后续 ADR，不在 0.1 强依赖。 |
| 分发 | APK 不含权重；外部导入 | 保持 APK 小、避免模型许可与商店体积问题。 |

模型文件必须由用户通过系统文件选择器导入，复制到 `filesDir/models/`。应用不包含下载逻辑，也没有网络权限。

## 3. Prompt 规范

```
System:
你是 Bitap 输入法的本地文本改写引擎。只输出改写后的文本，不解释、不寒暄、不加引号、不使用 Markdown。保留原意与语言；若要求翻译，只输出译文。不要展示思考过程。

User:
任务：{润色|精简|正式|译为英文}
原文：{user_text}
```

- `temperature = 0.2`，`topK = 20`，`topP = 0.9`，`maxTokens = 128`。
- 输入上限 512 字符；输出上限 3× 原文长度，且 ≤ 512 字符。
- 单轮无历史；不把上一次结果带入下一次。
- Qwen3 的 thinking 模式通过系统提示与 `/no_think` 风格指令抑制；若仍出现 ` thinking` 块，清理阶段移除。

## 4. 结果清理

`AiResultSanitizer` 负责：
1. 去掉首尾空白、包裹引号、代码围栏、Markdown 强调符；
2. 去掉「以下是…」「改写后：」等前缀；
3. 移除 ` thinking...<｜end▁of▁thinking｜>` 块；
4. 合并多余空行；
5. 若为空或超过长度上限，返回失败而非插入。

**任何情况下不自动插入**；只有用户点击「插入」才写回 `InputConnection`。

## 5. 状态与错误

```
NotInstalled → Importing → Loading → Ready ⇄ Running → Ready
                                  ↘ Error（可重试）
```

- 未安装：✦ 禁用；点击跳转模型管理。
- 加载失败：保留键盘输入能力；AI 面板显示「本地模型加载失败」。
- 推理失败/超时：面板内联重试；不阻断键盘。
- 低内存：捕获 `OutOfMemoryError`，关闭引擎并提示「设备内存不足」。

## 6. 延迟预算

| 阶段 | 目标 |
| --- | --- |
| 模型懒加载 | ≤ 10 s（首次） |
| 首 token | ≤ 2.5 s p50 / 8 s 上限 |
| 完整短句 | ≤ 8 s p50 / 20 s 超时 |
| 清理+预览 | ≤ 16 ms |

首次加载期间键盘仍可正常输入；AI 面板显示加载进度。

## 7. 评测集（0.1 人工）

20 条中英短句，覆盖：口语润色、商务正式、长句精简、中译英、含专有名词、含 emoji、空输入、超长输入。验收标准：18/20 输出可读且不改变原意；0 条自动上屏；0 条包含解释性前言。

## 8. 隐私不变量

- 不读取剪贴板、不读取屏幕、不访问联系人。
- prompt、结果、模型输入输出不写磁盘、不进日志、不进崩溃上报。
- 引擎关闭后不保留会话；每次改写新建短生命周期 Conversation。
- 无网络权限是无法绕过的硬边界，而不是设置项。
