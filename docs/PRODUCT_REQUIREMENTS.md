# 项目需求

## 1. 产品目标

Bitap 是面向 Android 的离线、隐私优先中文输入法。目标用户日常输入中文，穿插英文缩写、数字和标点，希望用更少的修正完成输入，同时控制本地学习与模型使用。

首要目标是无模型时也能可靠地打字。可选本地 AI 只在用户主动请求时补充拼音候选，不承担每次按键的核心解码。当前应用版本 0.1.0，仅支持 Android 13+、arm64-v8a。

## 2. 产品范围与当前状态

| 候选展开/翻页与触控 | 已实现；长候选分页已按可见行容量修复（进度§37），字体/横屏/更高密度布局待设备验证 | 显示页数与实际视口一致，避免必要候选被隐藏 |

| 云服务、账号、遥测、同步 | 当前范围外 | 不增加网络权限，不自动上传输入数据 |

## 3. 功能需求

### FR-01 输入正确性

所有字母、空格、标点、回车、退格、候选点击都有确定语义。查询结果必须属于当前编辑会话和 composing 版本。切字段、光标变化、选区变化、语言切换、旋转或请求取消后，过期候选不得写入，也不得产生副作用命令。

选部分候选只消费对应输入前缀，其余拼音继续编辑；不得按候选文本长度猜测消费范围。遇到查询失败、词库未准备好或长输入超预算，仍能删除、切换和提交原文，不能卡住输入法。

### FR-02 候选与分段选择

优先让正确完整句容易选择，同时保留可发现的分段入口。指标中的 Top5/前8返回项不等于手机屏幕首屏可见项。展开面板的行数、滚动、翻页与部分候选选择必须作为真实任务验证。

当前 partial 在第五个 full 后的策略存在已确认的分段选词额外滚动成本，详见 [进度](PROGRESS.md)。后续方案需要同时衡量完整句与 partial 的操作收益，不能只优化榜单分数。

### FR-03 纠错与混排

纠错保留原始输入出口，区分邻键、漏字、多字、交换和模糊音，不对专名/英文强制改写。中文、英文、数字和标点连续输入应有可解释规则；手动切换仍是可靠回退路径。该部分尚需 D06/D07 继续开发。

### FR-04 本地学习与隐私输入

仅保存用户允许的词/拼音、次数和来源等必要统计，不保存完整输入历史。提供学习开关和清除；单词删除、容量和跨片段造词为后续需求。密码字段与 `IME_FLAG_NO_PERSONALIZED_LEARNING` 必须关闭学习；密码字段不向 AI 提供上下文。

### FR-05 可选本地 AI

唯一生产入口是候选条 `✦ AI`，用于拼音候选。无模型时不初始化推理引擎，基础输入完整可用。结果必须用户选择才上屏，不自动替换整段或发送。

“取消请求”只停止生成；“关闭 AI”必须取消、等待退出并卸载运行时；删除模型与永久关闭是不同生命周期动作。光标/选区/会话变化后旧结果失效。运行资源未达预算时保持可选/实验性质，不靠杀 IME 进程解决。

### FR-06 引导、设置与无障碍

首次流程为启用 → 选择输入法 → 本地试打；模型导入属于可选增强。键盘高度与底部空间应可合理适配。TalkBack、字体放大、横屏、分屏和多 ROM 需要真实设备验证，不能仅以内容描述属性存在视为通过。

## 4. 非功能要求和阶段目标

以下为项目内部目标，不是当前已达到的结果，也不是未经测量的竞品标准。

| 维度 | 0.2 内测目标 | 验证方式 |
|---|---|---|
| 中文完整输入 | 冻结验收集 Top1≥75%、Top5≥90% | 分类、分母、hash 和置信区间同时报告 |
| 自然长句 | Top1≥50%、Top5≥80% | 包含超预算项的全量视图；另列有效长度视图 |
| 连续混排 | 合成事件正确率≥95% | 最终文本、选区、composing 和命令记录 |
| 输入正确性 | 核心矩阵中丢字/重复/跨字段写入零复现 | 明确样本量与平台，不承诺绝对零 bug |
| 可见反馈 | 目标主设备按键到可见反馈 p95≤50ms | 系统呈现与应用帧完成分开记录 |
| 候选查询 | 普通/长串 p95≤10/50ms | JVM 与 Android 分开，报告 p99 |
| 非 AI 内存 | 固定场景稳态 PSS≤100MiB、无长期增长 | 场景、构建、采样时点一致 |
| 关闭 AI | 10秒内 PSS 回到同场景基线+100MiB | native 与 PSS 均报告；目前尚非全场景达标 |
| 资源与隐私 | 无网络权限、无自动遥测、备份关闭 | 源码与 APK 权限同时检查 |

0.3 再考虑 Top1≥85%、Top5≥95%、更多设备与长期默认输入法试用。当前不以时间压力降低或更换指标分母来宣称达标。

## 5. 发布边界

编译、单测、lint、语料校验只证明相应工程检查通过。发布还需要冻结候选的独立质量验收、输入交互矩阵、资源预算、许可证及设备验证。未验证项明确列出，不用“工程交付完成”替代产品体验达标。
