# 后续开发路线图

## 1. 当前优先级

优先解决日常输入正确性与选词成本。当前仍以自研引擎为生产默认，Rime保留实验价值；不以“必须有AI”或“必须换引擎”作为路线前提。

| 顺序/任务 | 范围与依赖 | 验收与交付 |
|---|---|---|
| P0 候选面板与partial可发现性（D05/D08延续） | 解决每页6项但首屏仅4完整行、页间滚动保留；保持算法不变 | 展开/翻页/字体/横屏几何检查，完整句与partial操作成本对照，禁止仅报Top5 |
| P0 长输入预算UX | 超64输入可分段继续、删除/原文提交可靠；先定义消费规则 | 包含65–70及更长序列的最终文本/状态测试；全量与预算子集报告 |
| P1 D05召回/搜索/排序继续 | 固定当前资产和dev，定位正确路径丢失层次 | 一次一个机制，配对与消融、分类回退、延迟；微小dev涨分不宣称泛化 |
| P1 D06纠错 | 长串局部错拼、邻键/漏多字/交换、置信度/原文出口 | 专项隔离数据、正常输入误纠正率、专名/英文不被破坏、可撤销 |
| P1 D07连续混排 | 中文/英文片段/数字/标点tokenizer及状态规则 | 输入/光标/退格/切换完整事件；输出准确率与真实操作 |
| P1 D08触控 | 双指交叠、按下/抬起顺序、跨行/边缘/cancel、命中区域 | 可回放时间戳事件+真实双拇指试打，不只ADB单指 |
| P1 D09兼容性与AI剩余项 | Android13–16、多ROM/字段、TalkBack；AI关闭/取消固定场景 | 构建hash、状态矩阵；同场景10秒释放与取消无旧写入 |
| P2 D10学习/管理 | 200条容量/淘汰、分段造词、单条删除、清除 | 重启/删除/清除不复活；密码/隐私输入零写入 |
| P2 D11编辑效率 | 空格拖光标、删除加速、撤销、最近符号 | Unicode/选区正确，实际任务操作减少 |
| P2 D12性能 | trace后再优化重组、分配、查询和加载 | 固定设备p95/p99/PSS，长会话稳定性，避免盲目重写UI |
| P2 D13/D14引导与发布 | 启用试打、能力文案、版本/签名/依赖迁移/持续门禁 | 无模型完整试用，APK权限/来源/回退与未测项清晰 |
| 有条件 D04 Android PoC | 完整实用Rime方案先达到值得集成的dev质量 | 独立实验变体、NDK/JNI、真实消费/学习/取消、包体与同设备预算 |
| 后续 D15 | 英文预测、联想、双拼或九宫格择一 | 用户需求证据与独立预算，基础质量达标后开展 |

前两个P0可以作为不同批次推进；一个批次不同时改候选排列、排序权重、词库和预算。当前0.50权重只有小幅Top5收益且有shorthand回退，先保留可回退对照，不继续靠扫描更多权重当作主要研发路线。

## 2. 阶段退出条件

### 可继续内测

核心最终文本正确性无已知阻断，设备上的候选选择路径明确，长输入不会卡死；新功能有dev诊断与回归证据。每次交付列出剩余限制，不把小样本设备正例称总体通过。

### 0.2产品候选

达到 [需求](PRODUCT_REQUIREMENTS.md) 的质量/资源目标；冻结候选后有合法隔离的验收；完成真实字段、触控和设备矩阵；AI预算不过则维持明确实验状态。编译/门禁通过不能单独触发发布完成。

### 默认输入法试用

5–10位目标用户自愿连续试用，记录合成复现和经同意的汇总，了解退回其他输入法的原因；不默认采集真实聊天或全部按键。比较任务时间、修正和选择操作，不只比较候选Top1。

## 3. 给后续AI开发者的执行要求

```text
先读docs/README.md及当前进度、需求、评测规范，再核对git状态和源码。
保留离线无网络权限、当前生产默认与可回退接口；不要整仓重写。
每批选择一个主要问题或机制，先定义可复现输入、预期文本和验收层次。
先完成可执行实现与验证，不停留在泛泛建议；不新增无关主题或AI功能。
只在允许诊断的dev上选优；冻结v3不逐轮读取，不按验收句写词库/规则。
区分实际首屏可见与前N返回、rankCost与真实操作、JVM与Android时延。
报告全量分母及超预算输入，不隐藏负向类别或未测项。
源码、测试、评测原件/manifest和legal署名是受保护资产。
统一使用scripts/verify.ps1并按变更补专项；无设备就明确未测。
更新现有需求/进度/评测/路线图，不再生成多个互相冲突的最终报告。
交付包含：改动原因、文件、before/after、消融、测试、设备/hash、风险和回退。
```

## 4. 重新选型条件

当自研连续两轮在隔离开发/冻结验收中没有实质收益，或完整Rime组合在质量/维护成本上显示优势，重新比较引擎。决策必须覆盖输入正确性、候选组织、学习隐私、native生命周期、内存/时延/包体与许可；宿主DLL不可直接当Android实现。
