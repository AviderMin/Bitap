优先解决日常输入正确性与选词成本。当前仍以自研引擎为生产默认，Rime保留实验价值；不以“必须有AI”或“必须换引擎”作为路线前提。

## 2. 阶段退出条件

### 可继续内测

核心最终文本正确性无已知阻断，设备上的候选选择路径明确，长输入不会卡死；新功能有dev诊断与回归证据。每次交付列出剩余限制，不把小样本设备正例称总体通过。

### 0.2产品候选

达到 [需求](PRODUCT_REQUIREMENTS.md) 的质量/资源目标；冻结候选后有合法隔离的验收；完成真实字段、触控和设备矩阵；AI预算不过则维持明确实验状态。编译/门禁通过不能单独触发发布完成。

### 默认输入法试用

5–10位目标用户自愿连续试用，记录合成复现和经同意的汇总，了解退回其他输入法的原因；不默认采集真实聊天或全部按键。比较任务时间、修正和选择操作，不只比较候选Top1。

## 4. 重新选型条件

当自研连续两轮在隔离开发/冻结验收中没有实质收益，或完整Rime组合在质量/维护成本上显示优势，重新比较引擎。决策必须覆盖输入正确性、候选组织、学习隐私、native生命周期、内存/时延/包体与许可；宿主DLL不可直接当Android实现。
